# MVP Scope v1

## Included in v1
1. Авторизация через Telegram без отдельной страницы логина.
2. Создание группы расходов.
3. Добавление участников в группу.
4. Отправка invite-ссылки на группу расходов другу.
5. Переход по invite-ссылке сразу на страницу нужной группы.
6. Выбор участника при первом входе в группу по ссылке.
7. Сохранение привязки `telegram user -> group participant` в базе.
8. Автораспознавание участника при последующих входах в эту группу.
9. Создание расхода или поступления (тип, участник, описание, сумма, дата).
10. Выбор участников, между кем делить (по умолчанию поровну).
11. Экран балансов: кто кому сколько должен.
12. Базовый расчет рекомендаций по погашению.
13. Telegram `BackButton` для навигации на внутренних экранах с `v1`.

## Auth Decision (Fixed)
- Отдельной страницы логина нет.
- Используем пользовательские данные из Telegram Mini App.
- Next.js API валидирует Telegram payload и генерирует токен сессии.

## Not Included in v1
- Мультивалютность.
- Сложные сценарии сплита (доли, проценты, ручной точный split).
- Расширенная история изменений.
- Экспорт и интеграции.
- Push-уведомления.

## Acceptance Criteria
- Пользователь может создать группу и добавить минимум 2 участников.
- Пользователь может сгенерировать и отправить invite-ссылку на группу.
- Друг по invite-ссылке открывает именно эту группу.
- При первом входе друг выбирает, какой он участник в группе.
- Выбранный участник сохраняется в БД и привязывается к Telegram-пользователю.
- При повторном входе выбор участника не запрашивается повторно, если привязка уже есть.
- Пользователь может добавить минимум 1 расход.
- Балансы корректно считаются после каждого добавленного расхода.
- Экран итогов показывает понятный список для погашений.
- На стартовом экране `BackButton` скрыта, на внутренних экранах отображается и работает корректно.
