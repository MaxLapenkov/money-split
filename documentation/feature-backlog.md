# Feature Backlog

## Core
1. Онбординг и первый запуск.
2. Создание/редактирование группы.
3. Добавление и управление участниками.
4. Создание расхода/поступления (тип, участник, описание, сумма, дата).
5. Настройка распределения расхода (поровну / вручную / по долям).
6. Итоговый баланс по группе.
7. Генерация "кто кому платит".

## Extensions
8. История действий и редактирование расходов.
9. Приглашения в группу.
10. Экспорт/шаринг итогов.
11. Уведомления.
12. Мультивалютность.
