# Create Expense Page UI Spec (MVP)

### 1. Screen Purpose
Экран позволяет создать запись о движении денег в группе: выбрать тип операции (`Расход` или `Поступление`), выбрать участника, указать описание, сумму в рублях и дату, затем отправить форму кнопкой "Создать".

### 2. Wireframe
```text
┌────────────────────────────────────┐
│ [BackButton]  Новая трата          │
├────────────────────────────────────┤
│ Label: Тип операции                │
│ [ Расход ] [ Поступление ]         │
├────────────────────────────────────┤
│ Label: Участник                    │
│ [Select: список участников]        │
│ Hint: заплатил(а) / получил(а)     │
├────────────────────────────────────┤
│ Label: Между кем делим?            │
│ [Multi-select: участники группы]   │
│ По умолчанию: все участники        │
├────────────────────────────────────┤
│ Label: За что?                     │
│ [Input: например, Пицца]           │
├────────────────────────────────────┤
│ Label: Сумма (RUB)                 │
│ [Input: 0.00]                      │
├────────────────────────────────────┤
│ Label: Когда?                      │
│ [Date picker / date input]         │
├────────────────────────────────────┤
│ [MainButton: Создать]              │
└────────────────────────────────────┘
```

### 3. Layout & Spacing
- Контейнер: `max-width: 640px`, горизонтальные отступы `16px`.
- Базовая сетка: `8px`.
- Вертикальный gap между полями: `12px`.
- Отступ между секциями: `16px`.
- Учитывать safe area через `--tg-content-safe-area-inset-top/bottom`.

### 4. Colors
- Только Telegram tokens:
  - фон: `--tg-theme-bg-color`
  - фон секций/карточек: `--tg-theme-secondary-bg-color`
  - основной текст: `--tg-theme-text-color`
  - вторичный текст/hint: `--tg-theme-hint-color`
  - CTA: `--tg-theme-button-color` / `--tg-theme-button-text-color`
  - ошибки: `--tg-theme-destructive-text-color`.
- Light/dark режим определяется `WebApp.colorScheme`.

### 5. Typography
- Заголовок страницы: `1rem` / `600`.
- Label: `0.875rem` / `500`.
- Поля ввода: `0.9375rem` / `400`.
- Hint/error: `0.8125rem` / `400`.

### 6. Components (shadcn only)
- `ToggleGroup` или `Tabs`:
  - выбор `Расход` / `Поступление`.
- `Select`:
  - выбор участника (кто заплатил/получил).
- `Checkbox group` / `ToggleGroup` (multi-select):
  - выбор, между кем делим (по умолчанию все участники выбраны).
- `Input`:
  - поле "За что?",
  - поле суммы.
- `Input type="date"` (или `Popover + Calendar` из shadcn):
  - выбор даты.
- `Button`:
  - primary action "Создать" (опционально синхронизируется через Telegram `MainButton`).
- `Toast`:
  - ошибки server action.

### 7. Form Control and Validation
- Контроль формы: `react-hook-form`.
- Валидация: `zod` schema (расширение `createExpenseInputSchema`).
- Поля формы:
  - `type: "expense" | "income"`
  - `groupMemberId: string` (обязательно, кто заплатил/получил)
  - `splitBetween: string[]` (обязательно, минимум 1, по умолчанию все участники)
  - `note: string` (обязательно, label "За что?")
  - `amount: number` (обязательно, `> 0`)
  - `currency: "RUB"` (фиксировано)
  - `expenseDate: string` (обязательно)
- Кнопка "Создать" disabled, пока форма невалидна.

### 8. Dynamic Participant Hint
- Имя поля участника в форме: `groupMemberId` (единое имя, совпадает с API и DB).
- Под `Select` участника показывается динамичная подпись:
  - если выбран `Расход`: `"<Имя> заплатил(а) за что-то"`;
  - если выбрано `Поступление`: `"<Имя> получил(а) деньги за что-то"`.
- Пока участник не выбран:
  - для `Расход`: `"Участник заплатил(а) за что-то"`;
  - для `Поступление`: `"Участник получил(а) деньги за что-то"`.

### 9. Interactions
- Переключение `Расход`/`Поступление` мгновенно обновляет подпись под `Select`.
- По submit:
  - вызвать server action создания записи;
  - выполнить `revalidatePath` страницы группы;
  - показать success toast "Запись успешно создана";
  - очистить форму для ввода следующей траты (reset к дефолтным значениям).
- При ошибке:
  - показать toast;
  - сохранить введенные данные в форме.

### 10. Navigation
- Экран внутренний, `BackButton` отображается.
- `BackButton` возвращает на страницу группы.
- Поведение по правилам [[technical/telegram-miniapp-integration]].

### 11. Edge Cases
- В группе нет участников:
  - заблокировать форму и показать объяснение.
- Пустое описание/некорректная сумма/дата:
  - inline ошибки под полями.
- Сетевой сбой:
  - toast + возможность повторить submit без потери значений.
- Успешное создание:
  - success toast "Запись успешно создана" обязателен;
  - форма очищается и остается на этом же экране для быстрого ввода следующей записи.
