# Group Page UI Spec (MVP)

### 1. Screen Purpose
Единая страница группы для двух состояний:
- сразу после создания группы (onboarding-состояние без расходов);
- после добавления расходов (с обзором, расчетами и просмотрами).

### 3. Layout & Spacing
- Контейнер: `max-width: 640px`, горизонтальные отступы `16px`.
- Базовая сетка: `8px`.
- Каждый блок (`Обзор затрат`, `Задолженности`, `Просмотры`) как отдельный `Card`.
- Внутренний padding карточки: `16px`.
- Между карточками: `12px`.
- Учитывать safe area через `--tg-content-safe-area-inset-top/bottom`.

### 4. Colors
- Только Telegram tokens:
  - фон: `--tg-theme-bg-color`
  - фон карточек: `--tg-theme-secondary-bg-color`
  - основной текст: `--tg-theme-text-color`
  - вторичный текст: `--tg-theme-hint-color`
  - кнопки/CTA: `--tg-theme-button-color` / `--tg-theme-button-text-color`
  - link/action: `--tg-theme-link-color`.

### 5. Typography
- Заголовок карточки: `1rem` / `600`.
- Строки метрик: `0.9375rem` / `400`.
- Текст кнопок: `0.875rem` / `600`.
- Статусы просмотров: `0.8125rem` / `400`.

### 6. Components (shadcn only)
- `Card`:
  - блок onboarding-подсказки (State A);
  - 3 ключевых блока финансового состояния (State B).
- `Button`:
  - "Пригласить друзей" (State A),
  - "Ввести трату" (State A),
  - "Посмотреть все расходы",
  - "Отметить как оплаченное" для каждой рекомендации.
- `Badge` (опционально):
  - статусы просмотра (`просмотрено`, `не просмотрено`, `отметился`).
- `Separator`:
  - разделение строк внутри карточек.
- `Toast`:
  - результат действия "Отметить как оплаченное".

### 7. Block Details

#### 7.0 State A: Group Created
- Показывать верхнюю подсказку:
  - `Группа создана`
  - `Теперь вы можете`
  - CTA `Пригласить друзей`.
- `Пригласить друзей`:
  1) server action генерирует invite-ссылку;
  2) вызывается Telegram share (`WebApp.openTelegramLink(...)`).
- Второй CTA: `Ввести трату` -> переход на [[specs/create-expense-page-ui-spec]].

#### 7.1 Обзор затрат
- Отображать 4 обязательные строки:
  - `Это событие обошлось всем`
  - `Это обошлось вам`
  - `Вы оплатили`
  - `Вам задолжали`
- Под блоком кнопка `Посмотреть все расходы` с переходом на [[specs/all-expenses-page-ui-spec]].

#### 7.2 Как закрыть все задолженности?
- Список settlement-рекомендаций в формате:
  - `<Участник A> переводит <сумма> на счет <Участник B>`.
- Для каждой рекомендации:
  - кнопка `Отметить как оплаченное`.
- После отметки:
  - элемент либо скрывается из активного списка, либо помечается как `Оплачено`.

#### 7.3 Кто уже просмотрел группу?
- Список участников группы с состояниями:
  - `просмотрено`
  - `не просмотрено`
  - `отметился` (если пользователь подтвердил присутствие/ознакомление).

### 8. Interactions
- `Посмотреть все расходы` -> переход на экран/лист истории расходов.
- `Отметить как оплаченное`:
  - server action изменения статуса settlement;
  - `revalidatePath` страницы группы;
  - success toast.
- Статус `просмотрено` появляется, когда пользователь выбрал своего участника в процессе join/binding.
- Статус `отметился` появляется после явного действия пользователя (если кнопка включена).

### 9. Navigation
- Экран внутренний: `BackButton` отображается.
- Возврат по `BackButton` на Home или предыдущий экран.
- Поведение по [[technical/telegram-miniapp-integration]].

### 10. Edge Cases
- Нет расходов:
  - показывать State A (onboarding) с `Пригласить друзей` и `Ввести трату`.
- Нет активных задолженностей:
  - показать "Все расчеты закрыты".
- Нет данных просмотров:
  - отображать начальное состояние "Никто еще не просмотрел".
- Ошибка генерации invite-ссылки:
  - toast + возможность повторить.

### 11. Currency Note
- В MVP системная валюта `RUB`.
- Все суммы в интерфейсе отображаются в `RUB`.
